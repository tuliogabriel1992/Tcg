# TCG Companion

Aplicativo PWA para acompanhar decks, partidas, treinos, torneios e estatísticas de Pokémon TCG.

## Estado

Repositório inicializado. O pacote local de referência é `TCG_Companion_PWA_v1_5.zip` (ainda não enviado integralmente).

## Funcionalidades da versão de referência

- Cadastro e seleção de decks
- Partidas, treinos e torneios
- Pontuação de torneio: vitória 3, empate 1, derrota 0
- Estatísticas e matchups
- Temas inspirados em cidades de Kanto e jornada com insígnias
- Estrutura PWA com manifesto, service worker e ícones
